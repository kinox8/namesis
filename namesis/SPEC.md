# NAMESIS 細かい仕様

ゲーム内の数値の まとめ。くわしい設計の理由は [DESIGN.md](DESIGN.md)。

## 能力アップ (みんなムキムキ / みんなガチガチ / みんなかぜになれ / みんなかわしやすい)

- アンテナ: みんなムキムキ = 黒い 力こぶの うで / みんなガチガチ = 白黒 もようの かたい ボール / みんなかぜになれ = 白い かぜの うず / みんなかわしやすい = くるりと よける 白い 矢じるし (全体なので 黒い 輪つき)。
- たくわえる の アンテナ = バーベル (ふちは 黒・中は 白。少し 大きめ)、みんなたくわえる = 黒い ダンベル (輪つき)。みんなムキムキ の 力こぶの うでも ふちは 黒・中は 白で 少し 大きめ。
- 名前の 変更: みんなパワーアップ → みんなムキムキ、みんなガードアップ → みんなガチガチ、みんなスピードアップ → みんなかぜになれ (効果は 同じ)。

| 項目 | 値 |
|---|---|
| 対象 | 味方全員 (たおれている味方は のぞく) |
| 1回の上がり幅 | 1段階 |
| 最大 | 5段階 (6回目以降は「変化なし」) |
| 1段ごと | 能力 +50% (1段 ×1.5 / 2段 ×2.0 / 3段 ×2.5 / 4段 ×3.0 / 5段 ×3.5) |
| 続く長さ | 4ターン (かけ直すと 4ターンに もどる) |
| 消費MP | 10 |
| たおれたとき | 能力変化は 消える |

- 上がった能力は 攻撃なら 通常攻撃・スキルのダメージ、防御なら 受けるダメージ、素早さなら 行動順に 効く。
- みんなかわしやすい: 味方全員の 回避 +10% (1段ごと)。重ねがけ できる (5段 = +50% まで)。4ターン。MP 10。
- 能力変化の計算: `能力 × (1 + 0.5 × 段階)`。下がる場合は 1段 ×0.85 / 2段 ×0.65 / 3段 ×0.45 / 4段 ×0.25 / 5段 ×0.05。
- アップと ダウンは 同じ 段階を 上げ下げする (+5〜−5 の 1つの 数)。両方 もらうと 打ち消しあう (例: 攻撃▲2 に よわよわ → ▲1。▲1 に よわよわ → ±0。±0 に よわよわ → ▼1)。続く長さは 最後に かけた ときから 4ターンで、切れると 0 に もどる。
- ステータス枠には「攻撃▲3」「攻撃▼2」のように 段数が 出る。

## 能力ダウン (みんなのろのろ / みんなよわよわ / みんなやわやわ)

| スキル | 効果 | アンテナ |
|---|---|---|
| みんなのろのろ | 敵全体の 素早さを 1段 下げる | 棒の 両がわに さがった 黒い 鉄球 |
| みんなよわよわ | 敵全体の 攻撃を 1段 下げる | しおれて 下を むいた 花 |
| みんなやわやわ | 敵全体の 防御を 1段 下げる | ぺしゃんこに つぶれた 白い 箱 |

| 項目 | 値 |
|---|---|
| 段階ごと | 1段 −15% / 2段 −35% / 3段 −55% / 4段 −75% / 5段 −95% |
| 最大 | 5段 (それ以上は「これいじょう 下がらない」) |
| 当たる確率 | かならず (状態異常耐性・回避は 関係なし) |
| 続く長さ | 4ターン (かけ直すと 4ターンに もどる) |
| 消費MP | 10 |
| 出る確率 | 3つ 合わせて 名前の 約2% |

- 能力アップと 同じ 段階を 上げ下げする (例: 攻撃▲2 の 相手に よわよわ → 攻撃▲1)。
- ボス (モンスター) には 効かない (「ボスには きかない!」)。がんばれ・敵の AI も ボスしか いないときは 使わない。
- がんばれ: まだ 5段 下がっていない 敵が いれば 使う (同じ スキルは 1ターンに 1回)。

## ダメージ

| 種類 | 式 |
|---|---|
| 通常攻撃 | `攻撃 × 1.25 × 100 ÷ (100 + 防御)` × 0.88〜1.12 |
| 属性スキル | `200 × 威力 × 100 ÷ (100 + 防御 × 0.5)` × 属性倍率 × オーラ倍率 × かんむり倍率 × 0.9〜1.1 (攻撃力・パワーアップに よらない 固定の 強さ。かんむり倍率 = まおうのかんむり ×1.5) |
| 会心 (通常攻撃) | 6% + (自分の素早さ − 相手の素早さ) ÷ 2000 (+ オノ 5%)。相手の 防御を 無視した ダメージ (防御 0 として 計算) |
| そうこうげきの会心 | 6% (+ オノ 5%)。ダメージは 通常攻撃と 同じ |
| ぼうぎょ中 | 受けるダメージ ×0.5 |

- 属性倍率 = `1 − 0.2 × 耐性値` (0.3〜1.8)。耐性 +2 → ×0.6、弱点 −2 → ×1.4。
- 回避: 通常攻撃は 回避率そのまま、状態異常スキルは 回避率の半分。属性スキル (属性攻撃) は 外れない。ブラインド中の攻撃は +40% 外れる。

| 範囲 | 段階 (威力) | 威力の値 | MP |
|---|---|---|---|
| 1体 | 小さい / 強力 / 超強力 / 計り知れない | 0.63 / 1.16 / 1.47 / 3.0 | 3 / 5 / 7 / 10 |
| 3体 | 小さい / 強力 / 超強力 | 0.49 / 0.88 / 2.5 | 3 / 6 / 10 |

(威力は 以前より 30% 低い)

- 3体攻撃は ねらった相手 + いちばん近い2体。全員に 一斉に当たる。

- がんばれ (かしこい作戦) では、みんなふっかつ は たおれた 味方が 1体でも いれば かならず 使う (MP が たりて、アンテナ封じでない とき)。

- がんばれ: たくわえる (1体) は パーティで 今の 攻撃が いちばん 高い 味方に かける。何人 いても 同じ 1体に 重ね、×8 (3段) に なったら 次に 攻撃の 高い 味方に。
- かんぜんかいふく・みんなかいふく 以外の 回復量は `威力 × 0.92〜1.08 × (0.85 + 使う人の最大MP ÷ 110)`。

## 状態異常耐性

| 持ち主 | 耐性 |
|---|---|
| 体の色 | その色の 状態異常 +2 (赤 やけど / 青 みずびたし / 水色 しもやけ / 緑 かぜっぴき / 橙 どろだらけ / 黄 かんでん / 白 ブラインド / 紫 のろい / 桃 みりょう) |
| オーラ | 属性の色は その状態異常 +3 / 黒は 全状態異常 +1 |
| たいようの頭 | 全状態異常 +1 |
| どせいの頭 | 全状態異常 +1 |
| デビルの頭 | みりょう +3 |

- かかる確率 = `もとの確率 × (1 − 0.2 × 耐性)`。+2 → ×0.6、+3 → ×0.4、+5 以上 → かからない。
- 命名所の プレビューに「状態異常耐性」として 出る (例: 赤のたいよう →「全状態異常 +1」「やけど +3」)。

## ターンの流れ

1. コマンドを えらぶ (オンラインは 60秒)
2. みりょうの判定 (毎ターン)
3. ぼうぎょを ターンの最初に まとめて (MP +2)
4. 素早さ × 0.9〜1.1 の 高い順に 行動 (モンスターは 自分の順番で 続けて まとめて 動く)。0.9〜1.1 の ゆらぎは ターンの はじめに 決めるが、順番は 1人 動くたびに 今の 素早さで 並べなおす (みんなかぜになれ・みんなのろのろ は 同じ ターンの うちに 効く)
5. ターンの終わりに 状態異常のダメージ・残りターンを減らす・能力変化を減らす・MP +1

## 出生

- 1体につき 1回まで。色・頭・体型・背・各能力・格・スキル・見た目を 1/2 ずつ 受けつぐ。
- 頭の進化: トゲトゲ×トゲトゲ→たいよう / みかづき×みかづき→ほし / しかく×しかく→ブロック / おにぎり×しかく→ろっかく / ねこ×くま→うさみみ (ここまで かならず) / トゲトゲ×まる・たまご・もち・おにぎり→デビル (1/2) / ブロック×ブロック→キャッスル (1/2)
- どせい: たいよう×みかづき → 25% / 親の片方が どせい → 25% / 親が 2体とも どせい → かならず
- りゅうせい: ほし×たいよう → 25% / 親の片方が りゅうせい → 25% / 親が 2体とも りゅうせい → かならず (どせい × りゅうせい は それぞれ 25%)
- ステータスバー: 基礎の 理論上の 最大 (★なし・頭や色や スキルなしの ボーナスなし。HP 399 / MP 36 / 攻撃 114 / 防御 93 / 素早さ 114 / 回避 30%) が バーの 9割 (点線)。★・頭・色・スキルなし・格 1.14 を こえる ぶん (以前の 当たり名の 子・軍団の なかま) で 増えた ぶんは、その能力の 色で 光らせて 表示する。
- ふしぎな組み合わせは はじめから 祠に ぜんぶ 表示される。
- 世代: 名前から 生まれた なかまは 第0世代、その子は 第1世代、孫は 第2世代…
- 色は どちらかの親の色 (まざらない)。オーラは どちらかの親が 持っていれば 1/2、2体とも 持っていれば かならず 受けつぐ。
- 突然変異 (10%): 遺伝子が 1.35 に とどいていない 能力から 1つが 才能開花する。すでに ★ の 能力なら 今より 上に 引きなおす (例: ★1.20 → 1.21〜1.35)。
