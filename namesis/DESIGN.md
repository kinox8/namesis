# NAMESIS 設計メモ

> NAMESIS (ネームシス) = name × genesis。
> 名前をつけると、その名前に固有の能力を持つ個体が生まれる。強い名前を探して、コロシアムを勝ち抜くゲーム。

---

## 1. 電波人間のRPG の調査まとめ

### 基本
- 開発元はジニアス・ソノリティ。3DS で始まったシリーズで、2024年に Switch 向けの基本無料版『New 電波人間のRPG FREE!』が配信された。
- 周囲の「電波」から電波人間 (キャラ) を捕まえて仲間にする。能力は 1 体ずつ違う。
- ターン制のコマンドRPG。パーティは最初 4 人で、最大 8 人まで増える。

### 戦闘コマンド
| 種類 | コマンド | 内容 |
|---|---|---|
| パーティ全体 | がんばれ | 各自が自由に行動 (アンテナ・通常攻撃) |
| | そうこうげき | 全員で通常攻撃。対象が倒れると次の敵へ |
| | まもり | 1ターン ダメージ軽減 |
| | にげる | 逃走 (失敗あり) |
| 個別 | こうげき / とくぎ(アンテナ) / どうぐ / ぼうぎょ | |

- 全員のコマンドを選び終えてからターンが進む。決定するまでは選び直せる。
- 画面下に HP (緑) と AP (青) のステータス枠が並ぶ。AP を使ってアンテナ (スキル) を出す。

### 属性と体の色
- 属性は **火・氷・風・土・雷・水・光・闇** の 8 種類 (ほかに突然死、なし)。
- 6 属性は **火 > 氷 > 風 > 土 > 雷 > 水 > 火** の循環。光と闇は互いに弱点。
- **体の色が属性耐性を決める。**

| 色 | 耐性 | 弱点 | 備考 |
|---|---|---|---|
| 赤 | 火+2、やけど+1 | 水-2 | |
| 青 | 水+2、みずびたし+1 | 雷-2 | |
| 水色 | 氷+2、しもやけ+1 | 火-2 | |
| 緑 | 風+2、かぜっぴき+1 | 氷-2 | |
| 橙 | 土+2、どろだらけ+1 | 風-2 | |
| 黄 | 雷+2、かんでん+1 | 土-2 | |
| 白 | 光+2、ブラインド+1 | 闇-2 | |
| 紫 | 闇+2、のろい+1 | 光-2 | |
| 黒 | なし | なし | |
| 銀 | 防御力アップ | 水-2・雷-2 | |
| 金 | 獲得ゴールド増加 | 火-2・闇-2 | |
| 桃 | みりょう (確率) | 全属性 | |

- 各属性に対応する状態異常がある (火→やけど、水→みずびたし、氷→しもやけ、風→かぜっぴき、土→どろだらけ、雷→かんでん、光→ブラインド、闇→のろい)。

### 頭の形
- 形ごとにランクがあり、上位の形ほど **AP が高く、必要経験値が少ない**。
- 「出生」で上位の形に変化する系統がある (例: まる → 土星 → 太陽、しかく → ブロック → 要塞 → タワー)。

### アンテナ (スキル)
- 攻撃・回復・治療・増強・補助・お得などに分類。
- 例: ひのたま (火)、とがったこおり (氷)、つむじかぜ (風)、らくせき (土)、せいでんき (雷)、みずでっぽう (水)、よわいこうせん (光)、回復、能力アップ/ダウン、どく・ねむり・しびれ、全体攻撃、一撃 (突然死) など。
- 希少度があり、レアな個体ほど強いアンテナを持ちやすい。

### コロシアム
- 3DS 版には対人戦の「Wi-Fi コロシアム」があり、実力ごとのクラス分けがあった。

## 2. NAMESIS への落とし込み

| 電波人間のRPG | NAMESIS |
|---|---|
| 電波から電波人間を捕まえる | **名前から個体が生まれる** (名前 = シード) |
| 体の色 → 属性耐性 | 同じ 12 色と耐性・状態異常耐性をそのまま使う |
| 頭の形 → AP・成長 | 16 種類の頭。ランク 2〜4 は MP ボーナス。ランク 3〜4 は固有の効果 |
| アンテナ | スキル。**1体につき1つ**。頭のアンテナの形で どのスキルか わかる |
| 攻撃アンテナ (1体 / 3体 / 全体) | 属性攻撃は 1体・3体・全体の3範囲。名前は原作のアンテナ名を流用 (私的利用) |
| がんばれ / そうこうげき / まもり / にげる | 全体への指示は がんばれ / そうこうげき / まもり / リタイア。個別の指示は 下のキャラのアイコンから |
| AP | MP (ぼうぎょ と ターン経過で少し回復) |
| コロシアム | 6 つの大会。敵は 仮の名前 (ナナシA〜) で 色を変えて表示。勝つと 1 人スカウトでき、そのとき本当の名前がわかる。NAMESIS杯の先に 上級者向けの「名のある軍団」(固定パーティ) |

### 名前 → 個体の生成 (`js/chargen.js`)
1. 名前を NFKC で正規化 (全角/半角の違いを吸収。ひらがなとカタカナは別の名前)。
2. `cyrb128` で 128bit のハッシュ → `sfc32` 乱数のシードにする。**同じ名前は必ず同じ個体**。
3. 乱数を引く順番: 体の色 → 頭の形 → 名の格 → 6 能力の遺伝子 → スキル → 見た目。
   順番を変えると全員の能力が変わるので、追加は末尾に行う。
4. **名の格**: 1/40 で「当たり名」(全能力 +14%)、1/600 で「神名」(+32%)。
5. **遺伝子**: HP・MP・攻撃・防御・素早さは三角分布 (平均的な値が出やすい)。各能力 1/22 で「才能開花 ★」(上限突破)。
6. **回避** は 0 / 5 / 10 / 15 / 30 の5段階 (0 と 30 は各 6% と まれ)。**名力には含めない**。回避で背の高さが決まる (下表)。
7. **体型** (細 / 普通 / 太 = 3:4:3) は別系統の乱数で決まり、**背の高さと組み合わせて HP・素早さ・防御の「出る範囲」が決まる** (下表)。あとから倍率をかけるのではなく、その範囲の中でランダムに決まるので、太なら HP は必ず高め、細なら素早さは必ず高めになる。
8. **スキルなし** (12%): アンテナと MP を持たない。MP になるはずだった分を ほかの能力へ割り振る (攻撃 50% / HP 20% / 防御 15% / 素早さ 15%)。
9. **名力** = 回避をのぞく 5 能力を平均 100 に正規化した平均 × 5 + スキル希少度 × 10 + 頭ランク × 6 + 頭の効果ボーナス。
   スキルなしの MP は ほかの能力へ移しているので、そのまま数える (0)。

体型・背 ごとの範囲 (遺伝子 0〜1 の範囲。才能開花は そのまま上限を超える)

| | HP | 素早さ | 防御 |
|---|---|---|---|
| 太 | 0.6〜1.0 (高め) | 0〜0.45 (低め) | 0.25〜 |
| 普通 | 0〜1.0 | 0〜1.0 | 0〜1.0 |
| 細 | 0〜0.45 (低め) | 0.6〜1.0 (高め) | 0〜1.0 |
| 背: とても高い | +0.1 | −0.1 | 0.55〜1.0 (かたい) |
| 背: 高い | +0.05 | ±0 | 0.35〜1.0 |
| 背: 低い・とても低い | −0.05 / −0.1 | +0.1 | ±0 |

約8万名のシミュレーション (才能開花・スキルなし をのぞく 5〜95%):
- 太 の HP 252〜360 / 細 の HP 146〜252 → 太の HP は 必ず 細以上
- 細 の 素早さ 64〜101 / 太 の 素早さ 24〜60
- 太・とても高い は HP 平均 320・防御 61〜86 の **高耐久**

| 回避 | 出やすさ | 背の高さ |

| 0 | 6% | とても高い (脚が長い) |
| 5 | 29% | 高い |
| 10 | 32% | ふつう |

主系統の乱数 (色・頭・格・能力) は変えていないので、回避以外の能力は名前ごとに前と同じ。
スキルなし・回避・スキル・見た目は それぞれ別系統の乱数で決める。

| たまご | 1 | 素早さ +6 |
| もち | 1 | HP +12・防御 +3 |
| おにぎり | 1 | 攻撃 +5 |
| しかく | 1 | 防御 +6 |
| ねこ | 1 | 素早さ +8 |
| くま | 1 | 攻撃 +6 |
| ろっかく | 2 | 防御 +12・MP +2 |
| トゲトゲ | 2 | 攻撃 +12・MP +2 |
| ほのお | 2 | 攻撃 +8・素早さ +8・MP +3 |
| ブロック | 2 | HP +40・MP +3 |
| みかづき | 3 | 素早さ +8・回避 +5・MP +5 |
| ハート | 3 | HP +30・MP +6・みりょう 5% (毎ターン コマンド決定後、敵それぞれに判定) |

- みりょうされたキャラは **1ターン (1回の行動) 動けない**。
- 属性耐性は「体の色 + 頭の効果」の合計。

### スキル (1体につき1つ)
- 58% が属性攻撃、42% が補助。
- 補助: かいふく (3段階) / みんなかいふく / ふっかつ / みんなふっかつ / 能力アップ (全体のみ: みんなムキムキ・みんなガチガチ・みんなかぜになれ) / ねむり・どく・しびれ (1体・全体)。
- **ねむらせる**: 80% で ねむり (みんなねむらせる は 1体ごとに 15%)。1〜2ターン 動けないが、攻撃されると 目をさまし 次のターンから動ける。
- **しびれさせる**: 80% で まひ (みんなしびれさせる は 1体ごとに 15%)。1〜2ターン 動けない (雷の攻撃で起きる「かんでん」とは別)。
- **どくどく**: 50% で どく (みんなどくどく は 1体ごとに 30%)。**たおれるまで なおらず**、毎ターン 最大HPの 20% ダメージ。
- **grade (0〜5)** = 技の強さ。高いほど アンテナのアイコンが大きくなり、2 で まわる星、3 で 後ろに光の筋、4 で オーラと鼓動、5 で 虹色になる。
- 属性攻撃の属性は 85% で体の色と同じ。範囲は 1体 55% / 3体 27% / 全体 18%。
- 段階は **1体が 4 段階、3体・全体が 3 段階**。原作のアンテナ名の表 (1体 6・3体と全体 5) から、1体は 1・3・4・6 番目、3体・全体は 1・3・5 番目を使う。

  | 範囲 | 段階 (威力) | MP | 例 (雷) |
  |---|---|---|---|
  | 1体 | 小さい / 強力 / 超強力 / 計り知れない | 3 / 5 / 7 / 10 | せいでんき / スパーク / でんきだま / プラズマだま |
  | 3体 | 小さい / 強力 / 最大 | 3 / 6 / 10 | いなづま / せいてんのへきれき / てんのいかり |
  | 全体 | 小さい / 強力 / 最大 | 4 / 7 / 11 | ひゃくボルト / いちおくボルト / ひゃくおくボルト |

  MP は いちばん下が 何度も打てる・まんなかが まあまあ打てる・いちばん上が 数回 打てる くらい (MP は ふつう 15〜35)。上の段階ほど レアで、アンテナのアイコンも 派手になる。
- 3体攻撃は「ねらった相手 + いちばん近い 2 体」に当たる。
- 3体・全体の技は 端から順ではなく、**全員に一斉に** 当たる。
- スキルの乱数は能力とは別系統。スキルの仕様を変えても、名前ごとの能力・色・頭は変わらない。

| 火 / 水 / 氷 / 風 / 土 / 雷 / 光 / 闇 | ほのお / しずく / 結晶 / うず / 岩 / いなずま / きらめき / 黒いうず |
| かいふく | 中に くるっと線が入ったハート |

### 上級者向け: 名のある軍団 (固定パーティ)
NAMESIS杯を 制覇すると 挑戦できる。名前から生まれる個体ではなく、色・頭・体型・背・スキル・能力を 決めてある敵 (`NS.BOSS_PARTIES` / `NS.makeBoss`)。
- 仮の名前ではなく 本当の名前で戦い、名前は だいだい色で表示。同じ名前を 命名所でつけても 別の個体が生まれる。
- **勝つと、まだ なかまにいない メンバーから ランダムで 1体が なかまになる** (スカウトの代わり)。6回勝てば 全員そろう。
- 敵も がんばれ と同じ かしこい作戦 (`planSmart`) で行動する。
- 大会の札に メンバー全員の姿が出るので、相手に合わせて パーティを組める。

### 命名所
- プレビューは全身。ドラッグで くるっと回して 後ろ姿も見られる。パーティ枠・なかま一覧・10連も全身の絵 (縮尺は全員共通なので 背の違いが分かる)。
- ドラッグ&ドロップで編成: なかま → 枠 (埋まっていれば 入れ替え) / 枠 → 枠 (並べかえ) / 枠 → なかま一覧 (外す)。指で操作するときは 長押しで つかむ。
- **パーティの枠は 固定ヘッダー**: なかま一覧を スクロールしても 上に残るので、そのまま ドラッグで入れられる。
- **パーティ保存**: ふだんは たたんである (アコーディオン)。「＋ 今のパーティを 保存」で 枠が 1つずつ ふえる (20こまで)。それぞれ よびだす / 上書き / けす ができ、コロシアム画面の 番号ボタンでも 切りかえられる。外した なかまは よびだすときに のぞかれる。
- 名前から生まれない個体 (紅蓮騎士団の なかま・出生の子) は、なかま一覧では 特別なキー (`\uE000boss:…` / `\uE000kid:…`) で持つ。`\uE000` は 入力した名前からは 消えるので、名前と まざらない。

### 精霊の祠 (出生)
2体の なかまを かけあわせて 子を生む (`NS.breed` / `NS.makeChild`)。
- **1体につき 1回まで**。親は いなくならない。子も 1回 親になれる (第3世代、第4世代…と続く)。
- 子は 色・頭・体型・背・スキル・**能力の遺伝子ごと** (HP・MP・攻撃・防御・素早さ)・格・顔のパーツ・模様を それぞれ **1/2 で** どちらかの親から受けつぐ。
  能力は 遺伝子 (体型の範囲の中の位置) で受けつぐので、「太なら HP 高め」の決まりは 子でも 守られる。
- 同じ2体からは いつも同じ子が生まれる (親のキーから 乱数を作る。やり直しても 変わらない)。
- 子の名前は 自由。はじめは 親の名前を 半分ずつ つないだもの (🔀 で 順番を入れかえ)。
- **頭の進化** (必ず起きる): トゲトゲ × トゲトゲ → たいよう (言い伝えとして はじめから わかる) / みかづき × みかづき → ほし / しかく × しかく → ブロック / おにぎり × しかく → ろっかく / ねこ × くま → うさみみ
- **色まざり** (1/3): 赤×青→紫 / 赤×黄→橙 / 青×黄→緑 / 青×白→水色 / 赤×白→桃 / 白×黒→銀 / 銀×黄→金
- **突然変異** (10%): 能力の1つが 才能開花する。
- 見つけていない組み合わせは 祠の一覧で 「？？？ × ？？？ → たいよう」のように 結果だけ わかる。2体を えらんだとき 組み合わせが 当たっていれば「ふしぎな力を 感じる…」と出る。
- 紅蓮騎士団の なかまも 親になれる (能力から 遺伝子を 逆算する)。
- 儀式: 床の魔法陣の上で 親が光って浮かび、光が 中央に集まって 子が 空から降りてくる。

### バトルの指示
- パネルの4つは 全体への指示: がんばれ / そうこうげき / まもり / リタイア。
- **がんばれ (とオート)** の決まり (`bestAction`):
  - かいふく: 味方が ひとりでも HP 50% を切っていたら 使う (切っていなければ 攻撃)。
  - ふっかつ: たおれた味方が いれば 使う。
  - そのほかの スキル (攻撃・状態異常・能力アップ): MP があれば 使う。
  - ねらう順: **ふっかつ・かいふく を持つ敵から**。その中で いちばん効く (たおせる) 相手。
  - 味方どうしで 予想HPを共有して、倒しすぎ・回復しすぎを防ぐ。紅蓮騎士団も 同じ決まりで動く。
- **敵の HP は 見えない** (頭の上のバーも、ねらう相手の一覧にも 出さない)。ダメージの数字は 出る。
- キャラは 敵も味方も **横一列** に並ぶ (人数が多いと 間隔をつめる)。
- 下のキャラのアイコンを クリックすると そのキャラだけ 個別に指示できる (こうげき / ぼうぎょ / スキル)。アイコンに指示内容の札が出る。
- 個別に指示したキャラは そちらを優先し、ほかのキャラが 全体の指示に従う。

### 演出 (ゆっくりめ)
- 1行動は ×1 で約2.5秒 (以前の約2.5倍)。全体の速さは `js/engine3d.js` の `NS.PACE` で調整できる (大きいほど遅い)。
- ターン開始・BATTLE START・VICTORY / DEFEAT のバナー
- スキルのカットイン (顔・スキル名・アンテナのアイコン) と、足元の魔法陣
- 攻撃のヒットストップ、会心はスローモーション + カメラが寄る、弱点は「じゃくてん!」表示
- 走ると砂ぼこり、倒れると ふわっと浮いてから倒れて 頭の上に星が回る
- 勝利時の紙吹雪

### バトル計算 (`js/battle.js`)
- 行動順: 素早さ × 乱数(0.8〜1.2)。ぼうぎょはターンの最初。
- 通常攻撃: `攻撃 × 1.25 × 100 / (100 + 防御)` × 乱数(0.88〜1.12)。会心 6% (×1.6)。ぼうぎょ中は半減。
- スキル: `攻撃 × 1.25 × 威力 × 100 / (100 + 防御 × 0.5)` × 属性倍率。属性倍率 = `1 − 0.2 × 耐性値` (耐性+2 → ×0.6、弱点−2 → ×1.4)。
- 回避: 通常攻撃は回避率そのまま、スキルは半分。ブラインド中の攻撃は +40% 外れる。
- 属性攻撃は 20% (全体は 12%) でその属性の状態異常。体の色の状態異常耐性があると確率 −60%。
- 能力変化は ±2 段階・4 ターン。毎ターン MP +1、ぼうぎょで MP +2。

### 見た目 (`js/figure.js`)
電波人間の「フードをかぶった着ぐるみ」の顔を参考にしている。
- 体の色の 黄 は 金と見分けやすいよう 明るいレモン色。金は 全属性耐性 +1 (弱点なし) と 名声 +50%。
- 頭 = 体の色のフード。正面に 肌色の顔がのぞく穴がある (顔のふちに影は入れない)。顔の大きさと位置は頭の形ごとに調整。
- みかづき の頭は 三日月の形のフード: 左上へ高く、右へ低く 角がのびて、高い角の先は サーモン色。角は顔と同じ面にあるので、横を向くと 幅が縮み、後ろを向くと 左右が入れかわる。
- 顔は **デフォルメ (ゆるキャラ風)**: はなれた小さな目・小さな口・大きなほっぺ。まゆと鼻は描かない (おこった顔のときだけ 小さなまゆ)。
- 前髪 7 種 (なし / ぱっつん / 流し / まんなか分け / ギザギザ / ボブ / もこもこ) × 髪色 9 色。毛の線は入れず ぺたっと塗る。
- 目 15 種 (てん・まめ・くりくり・^ ^・ー ー・きらきら・◡ ◡・ちょん・うるうる・ぎょろ・ほし・ハート・ねむ・たれ目・ぐるぐる)。
  目の大きさ 4 段階 (大きい目も)・はなれ具合 3 段階・高さ 3 段階 で 個性が出る。
- まゆ (なし / まろまゆ / ふと / ほそ)、ほっぺ (まる / だえん / 斜線 / なし)、口 7 種 × 大きさ 3 段階、メガネ。
- 二つ名 (「疾風の」など) は 表示しない。
- 模様 3 種 (無地 / 水玉 / まだら) をフードと胴体に。黒っぽい体の水玉は カラフルになる。模様は球の表面の点として持っているので、振り向くと回り込む。
- 見た目は能力とは別系統の乱数なので、見た目を変えても能力は変わらない。

## 3. 2D なのに奥行きを感じさせる工夫 (`js/engine3d.js` ほか)

WebGL は使わず、Canvas 2D の上に小さな 3D パイプラインを自作している。

- **透視投影カメラ**: 闘技場・観客・柱・キャラ・エフェクトの位置はすべて 3D 座標。毎フレーム投影するので、手前ほど大きく、奥ほど小さい。
- **常に揺れるカメラ**: 待機中もゆっくり揺れて視差が生まれる。行動のたびに行動者と標的へ寄り、敵のターンは横に回り込み、勝利時は味方の正面まで回り込む。
- **奥行きソート**: キャラ・柱・かがり火・パーティクルを、カメラからの距離で並べ替えてから描く。
- **キャラは 2D の図形 + 疑似回転**: カメラとの角度から「向き」を計算し、顔・耳・腕・リボンを回り込ませる。四角い頭は面ごとに陰影をつけた本物の立方体として描く。味方は背中、敵は正面が見える。
- **球体の陰影**: 放射グラデーション + ハイライトで、つるっとしたおもちゃの質感を出す。
- **床に落ちる影・リング**: 足元の影や選択リングは床の上の楕円として投影するので、正しくパースがかかる。
- **ワールド空間のエフェクト**: 火の玉の弾道、落雷、岩、ダメージ数字も 3D 座標で飛ぶ。
- **観客席・天幕・ほこり**: 背景に何層もの奥行きを重ねる。観客は大ダメージで沸く。

## オンライン対戦 (`server.js` / `js/online.js`)
- **しくみ**: サーバーは 2人に 同じシード (乱数のたね) と 両方のパーティを 配り、毎ターン 2人のコマンドを 中継するだけ。
  バトルの計算は それぞれの画面で行い、同じシード・同じコマンドなので **同じ結果に なる** (ロックステップ)。
  - 勝敗に関わる乱数 (行動順・命中・ダメージのぶれ・会心・状態異常・ふっかつ) は バトルごとの シード付き乱数 `battle.rnd` から引く。演出の乱数は ふつうの Math.random。
  - 乱数を引く順番を そろえるため、全員の並びは「部屋をつくった側 → 入った側」(`units`)。複数の相手に 一斉に当たる技は、演出の前に 結果を 先に決める。
  - 毎ターン 状態のしるし (全員の HP・MP など) を送り、2人で ちがったら サーバーの ログに「同期ずれ」と出る。
  - 2人が 同時に全滅したら 引き分け。
- **通信**: ふつうの HTTP のみ (返事を 最大25秒 待たせる ロングポーリング)。Cloudflare のトンネル越しでも 切れにくい。依存パッケージなし。
- **部屋**: 「部屋をつくる」で 4けたの 部屋番号。番号を入れるか、ロビーの「まっている部屋」から 入ると 対戦開始。ロビーを はなれると 部屋は とじる。
- **パーティ**: 名前の個体は 名前だけ、紅蓮騎士団の なかまは 番号、出生の子は 記録ごと 送る。受けとった 出生の子は 値を 安全な範囲に そろえてから 作る (自分の側も 同じ手順で作るので 能力が かならず一致する)。
- **ターン**: 制限時間 60秒。すぎると のこりは がんばれ で動く。オートは 使えず、速さは ×1 に そろう。
- **はじめ**: 2人の 名前・名声・戦績を VS 画面で 見せてから 始まる。
- **ほかのプレイヤーの パーティ**: ロビーに 名声の高い順で 並ぶ (サーバーに 保存されている パーティ)。「NPC と たたかう」で その パーティを NPC (がんばれ と同じ作戦) が動かす 相手と たたかえる。戦績には 入らない。
- **切断**: ページを とじる・読みこみ直す・45秒 音沙汰がない と 対戦から ぬけた あつかい。ぬけた人は その場で 負けが つき、対戦には もどれない。残った人は あいての パーティを NPC (がんばれ と同じ 作戦) が 動かす 相手と 最後まで たたかい、その結果が 残った人の 戦績になる。
- **こうさん**: 負けになる。**戦績**: 2人の 報告が そろったら 記録 (勝ち・負け・引き分け)。ロビーに 上位10人の ランキング。
- **ログイン**: 名前 (12文字まで) と パスワード (4文字以上)。パスワードは scrypt + ソルトで保存。HttpOnly の クッキーで 30日 ログインしたまま。5回 まちがえると 30秒 待ち。
- **セーブ**: ゲストは この端末 (localStorage)。ログイン中は サーバー (`data/saves/`) に 1.2秒ごとに まとめて保存し、この端末にも 写しを置く。
  はじめて 登録したときは その端末の データを 引きつぎ、サーバーに データがある アカウントは サーバーの データで遊ぶ。ログアウトすると ゲストの データに もどる。
