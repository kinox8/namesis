# NAMESIS (ネームシス)

名前をつけると、その名に宿る能力を持ったキャラクターが生まれる。
強い名前を探してパーティを組み、コロシアムを勝ち抜くコマンドバトルゲーム。

## 遊び方

`index.html` をブラウザで開くだけで動きます (ビルド不要・依存なし)。この場合 ログインと オンライン対戦は 使えません。

### サーバーで動かす (ログイン・オンライン対戦つき)

```bash
node server.js 8080
```

→ http://localhost:8080

友だちと 遊ぶときは、別のウィンドウで Cloudflare のトンネルを ひらいて、表示された `https://〜.trycloudflare.com` の URL を 教える:

```bash
cloudflared tunnel --url http://localhost:8080
```

- データ (アカウント・セーブ・戦績) は `data/` に 保存される。消すと 全員の アカウントが 消える。
- ログインは 名前と パスワードだけの かんたんなもの (パスワードは scrypt で ハッシュ化して保存)。
- サーバーを 止めると 対戦中の バトルと 部屋は なくなる (アカウントと セーブは 残る)。

## 画面
- **命名所**: 名前を入れると、その名前の個体 (色・属性・頭の形・能力・スキル・ランク) がすぐ表示される。気に入ったら「なかまにする」。「10連 命名」でランダムな名前をまとめて試せる。パーティは「パーティ保存」(ふだんは たたんである) に 20組まで 保存できる。
- **コロシアム**: 6 つの大会。勝つと次の大会が開き、戦った相手を 1 人スカウトできる。NAMESIS杯を制覇すると 上級者向けの「紅蓮騎士団」(キングフレイム卿 ひきいる 固定パーティ) に挑戦でき、勝つと メンバーが 1体 なかまになる。
- **精霊の祠**: 2体の なかまを かけあわせて 子を生む (1体につき 1回まで)。色・頭・能力などを 1/2 で受けつぎ、トゲトゲ × トゲトゲ で たいようの頭に進化する。「転生の儀」で 3体だけ のこして ほかと お別れすると、全員の 出生ずみが リセットされる。
- **フリーバトル**: 好きな名前を相手チームにして戦う。
- **オンライン対戦** (サーバーで 起動したとき): ログインして 部屋を つくるか、4けたの 部屋番号・まっている部屋の 一覧から 入る。1ターンの 制限時間は 60秒 (オートなし・速さ ×1)。とちゅうで 切断すると 負けになり、あいては NPC と 最後まで たたかう。戦績と ランキングが 残る。ほかのプレイヤーの パーティを 見て、NPC として たたかうことも できる。
- **ログイン** (タイトルの 左上): ログインすると データが サーバーに 保存され、ほかの端末でも つづきから 遊べる。はじめて 登録したときは その端末の データを 引きつぐ。

## バトル
- パネルの4つは 全体への指示: がんばれ (おまかせ) / そうこうげき / まもり / リタイア
- 下のキャラのアイコンをクリックすると、そのキャラだけ 個別に指示できる (こうげき / ぼうぎょ / スキル)
- 個別に指示していないキャラは 全体の指示に従う
- オート / 速度 (×1〜×3) は右上のボタン
- 敵の HP は 見えない
